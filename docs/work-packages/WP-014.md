# WP-014: Web-Grundgerüst: PWA, Routing, Login

## Ziel
Die Web-App ist als PWA installierbar, hat Login/Registrierung und ein Design-System im Stil von D-008.

## Scope
**Drin:**
- React + Vite, Routing (Login, Registrieren, Lobby, Tisch, Rangliste, Einstellungen)
- PWA-Manifest, Icons (eigene), Service Worker nur für statische Assets
- Design-Tokens (Farben, Abstände, Typo) im PokerStars-Stil ohne Originalassets
- API-Client mit relativen URLs, WebSocket-URL aus `location` (D-014)
- Einstellungen: Ausrichtung Auto/Hoch/Quer (lokal gespeichert, D-009)

**Nicht drin:**
- Tischansicht (WP-016)

## Akzeptanzkriterien
- [ ] Registrieren, Login, Logout funktionieren gegen den echten Server
- [ ] App lässt sich auf iOS und Android zum Homescreen hinzufügen und startet im Vollbild
- [ ] Komponenten-Tests für Login/Registrierung inkl. Fehlermeldungen
- [ ] Keine absoluten Hosts/Ports im Frontend-Code

## Tests
Komponenten-Tests (Vitest + Testing Library).
