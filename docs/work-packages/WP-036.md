# WP-036: Blinds nach Anzahl Hände erhöhen

## Ziel
Beim Erstellen eines Tisches kann man wählen, ob die Blinds nach Zeit (alle X Minuten) oder nach Händen (alle N Hände) steigen.

## Scope
**Drin:**
- Engine: Blind-Struktur `increasing` bekommt eine Variante „alle N Hände“ (Level-Index aus der Handnummer statt aus der Zeit); bestehende Zeit-Variante bleibt unverändert und abwärtskompatibel
- Protokoll/Validierung der Tisch-Einstellungen, Server, Persistenz (falls Blind-Struktur gespeichert wird)
- Tisch-Erstellen-Formular: Umschalter Zeit/Hände und Eingabe der Anzahl
- Anzeige am Tisch („nächstes Level in N Händen“ statt Zeit, wo heute die Zeit steht)

**Nicht drin:**
- Kombination aus Zeit und Händen

## Akzeptanzkriterien
- [x] Engine-Tests: Level steigt genau nach N Händen, bleibt nach dem letzten Level
- [x] Validierung lehnt ungültige Werte ab (Test)
- [x] Formular erlaubt beide Varianten (Komponenten-Test)
- [x] Bestehende Tische/Runden mit Zeit-Struktur funktionieren unverändert
