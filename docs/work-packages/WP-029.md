# WP-029: Admin-Dashboard

## Ziel
Admins sehen auf einer eigenen Seite, was auf der Plattform los ist, und können die Aktionen aus WP-028 per Klick ausführen.

## Scope
**Drin:**
- Route `/admin`, nur für Admins sichtbar (Menüpunkt + Server-Prüfung)
- Übersicht: aktive Tische und Spieler online, Runden heute/Woche, Server-Health, letztes Backup
- Feedback-Liste mit „erledigt“
- Spielerliste mit Sperren/Entsperren, Tische schließen
- Audit-Log ansehen

**Nicht drin:**
- Spielgeld/Punkte manuell ändern

## Akzeptanzkriterien
- [ ] Nicht-Admin sieht weder Menüpunkt noch Seite (Test)
- [ ] Feedback lässt sich als erledigt markieren (Löschfrist D-025 greift)
- [ ] Mobil bedienbar (Visual-Test)

## Tests
Komponenten-Tests, Visual-Baseline, API-Tests aus WP-028 wiederverwendet.
