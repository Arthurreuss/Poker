# WP-012: Zeitlimit, Zeitbank und Reconnect

## Ziel
Der Tisch blockiert nie, und Spieler können nach einem Verbindungsabbruch nahtlos weiterspielen (D-013).

## Scope
**Drin:**
- Server-Timer pro Zug + Zeitbank; bei Ablauf Check, sonst Fold
- Getrennte Spieler bleiben sitzen, werden automatisch gecheckt/gefoldet, zahlen Blinds
- Reconnect mit derselben Session liefert sofort den aktuellen Zustand inkl. eigener Karten
- Client erkennt Abbrüche (Heartbeat) und verbindet sich mit Backoff neu

**Nicht drin:**
- UI-Darstellung des Timers (WP-018)

## Akzeptanzkriterien
- [x] Test mit gefälschter Uhr: Ablauf → automatische Aktion, Zeitbank wird verbraucht
- [x] Abbruch mitten in der Hand → Reconnect → identischer Zustand
- [x] Zwei Tabs desselben Spielers: neuere Verbindung übernimmt, ältere wird sauber getrennt
