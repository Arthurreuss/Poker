# WP-021: Backups und Betrieb

## Ziel
Prod-Daten sind gesichert und der Mac hält den Dienst am Laufen.

## Scope
**Drin:**
- Automatisches tägliches `pg_dump` mit Aufbewahrung (z. B. 7 täglich, 4 wöchentlich) in einen Ordner außerhalb von Docker
- Restore-Skript und getesteter Restore
- Mac wach halten (Anleitung: Energieeinstellungen / `caffeinate`), Docker-Autostart
- Einfaches Monitoring: Healthcheck-Status, optional Benachrichtigung

**Nicht drin:**
- Off-Site-Backups (später)

## Akzeptanzkriterien
- [x] Backup läuft automatisch und ist im Zielordner sichtbar
- [x] Restore in eine leere DB getestet und in OPERATIONS.md dokumentiert
- [ ] poker-prod startet nach einem Neustart des Macs ohne Eingreifen: Docker Desktop startet beim Login (`AutoStart: true` in `settings-store.json`) und alle prod-Container haben `restart: unless-stopped`

## Tests
Restore-Test als Skript.
