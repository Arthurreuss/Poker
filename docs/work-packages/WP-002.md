# WP-002: Docker-Entwicklungsumgebung (dev, localhost)

## Ziel
`docker compose up` startet auf dev Postgres, Server und Web mit Hot-Reload unter localhost:4310.

## Scope
**Drin:**
- `compose.dev.yml`, Compose-Projektname `poker-dev`
- Postgres 16 (Volume `poker-dev-db`, Host-Port 127.0.0.1:4312)
- Server-Container mit Watch-Mode (127.0.0.1:4311), `GET /api/health`
- Web-Container mit Vite (127.0.0.1:4310), Proxy für `/api` und `/ws` auf den Server
- `.env.example` mit allen Variablen
- npm-Skripte `dev:up`, `dev:down`, `dev:logs`

**Nicht drin:**
- Prod-Setup (WP-003)
- Datenbankschema (WP-009)

## Akzeptanzkriterien
- [ ] `npm run dev:up` startet alle Dienste, http://localhost:4310 zeigt die Web-App
- [ ] http://localhost:4310/api/health liefert über den Vite-Proxy `ok` inkl. DB-Verbindung
- [ ] Code-Änderungen in Server und Web werden ohne Neustart übernommen
- [ ] Alle Ports nur an 127.0.0.1 gebunden und aus 4310–4319 (D-006); keine Kollision mit Jarvis-Containern
- [ ] Keine Hostnamen/Ports im Code, nur Umgebungsvariablen (D-014)

## Tests
Integrationstest für `/api/health` (Server gegen Test-DB); manueller Smoke-Test per `dev:up` im WP-Log dokumentiert.
