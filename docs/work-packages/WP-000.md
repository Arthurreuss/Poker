# WP-000: Arbeitsweise und Doku-System

## Ziel
Es gibt ein festes System, wie wir arbeiten, Fortschritt tracken und Drift zwischen Doku und Realität verhindern.

## Scope
**Drin:**
- CLAUDE.md, WORKFLOW.md, PROGRESS.md, DECISIONS.md, ARCHITECTURE.md, WP-Vorlage
- Doku-Check (`npm run docs:check`) und Tabellen-Generator (`npm run docs:sync`)
- Tests für den Doku-Check
- Pre-Commit-Hook

**Nicht drin:**
- Poker-Code, Docker-Setup, Arbeitspakete für das Spiel (→ nächster Schritt)
