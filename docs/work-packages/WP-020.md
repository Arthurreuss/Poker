# WP-020: E2E-Smoke-Test

## Ziel
Ein automatischer Test beweist, dass das Gesamtsystem funktioniert.

## Scope
**Drin:**
- Playwright: zwei Spieler registrieren sich, Tisch erstellen, beitreten, Runde bis zum Ende spielen
- Lauf gegen die dev-Docker-Umgebung und gegen das Prod-Setup (localhost:4320)
- Eingebunden in `npm run release`

**Nicht drin:**
- Lasttests

## Akzeptanzkriterien
- [x] E2E läuft stabil 10× hintereinander grün
- [x] Release bricht ab, wenn E2E fehlschlägt

## Tests
Der Test selbst (`apps/web/e2e-game/smoke.pw.ts`); dazu `scripts/test/e2e-origin-proxy.test.mjs` (Origin-Proxy) und `scripts/test/release-verify.test.mjs` (Abbruch des Releases, trocken mit Stub-Befehlen).

## Betroffene Doku
- docs/OPERATIONS.md: Release-Ablauf
