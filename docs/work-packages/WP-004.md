# WP-004: Engine: Karten, Deck, Mischen

## Ziel
Die Engine kann Karten darstellen und ein faires, reproduzierbar testbares Deck mischen und austeilen.

## Scope
**Drin:**
- Typen für Rang, Farbe, Karte; kompakte String-Darstellung (`As`, `Td`)
- Deck mit 52 Karten, Fisher-Yates-Shuffle
- Injizierbare Zufallsquelle: in Tests per Seed, im Betrieb `crypto.randomInt`

**Nicht drin:**
- Handbewertung (WP-005)

## Akzeptanzkriterien
- [x] Deck enthält genau 52 verschiedene Karten
- [x] Gleicher Seed → gleiche Reihenfolge, anderer Seed → andere
- [x] Produktion nutzt kryptografisch sichere Zufallszahlen
- [x] Statistischer Test: Verteilung der ersten Karte über viele Mischungen ist plausibel gleichverteilt
