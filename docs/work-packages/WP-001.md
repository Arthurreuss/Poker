# WP-001: Monorepo-Grundgerüst und Tooling

## Ziel
Ein lauffähiges TypeScript-Monorepo, in dem `npm run check` Typecheck, Lint, Tests und Doku-Check aller Teile ausführt.

## Scope
**Drin:**
- npm-Workspaces: `packages/engine`, `apps/server`, `apps/web` (jeweils minimaler Platzhalter mit einem Test)
- Gemeinsame `tsconfig.base.json` (strict), ESLint + Prettier
- Vitest in allen Workspaces
- `npm run check` = Doku-Check + Typecheck + Lint + Tests
- `.nvmrc` (Node 22)

**Nicht drin:**
- Docker (WP-002)
- Fachliche Logik

## Akzeptanzkriterien
- [ ] `npm install && npm run check` läuft auf einem frischen Klon grün
- [ ] Jeder Workspace hat mindestens einen Test, der in `npm test` mitläuft
- [ ] Ein absichtlicher Typfehler oder Lint-Fehler lässt `npm run check` scheitern
- [ ] Doku-Check bleibt Teil von `npm run check`
- [ ] ARCHITECTURE.md beschreibt die Workspace-Struktur

## Tests
Platzhalter-Tests je Workspace; bestehende Doku-Check-Tests laufen weiter.

## Betroffene Doku
- ARCHITECTURE.md: Workspaces, Skripte; README: Setup
