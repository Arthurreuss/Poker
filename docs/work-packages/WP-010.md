# WP-010: Accounts: Registrierung, Login, Sessions

## Ziel
Spieler können sich offen registrieren, an- und abmelden (D-011).

## Scope
**Drin:**
- `POST /api/register`, `/api/login`, `/api/logout`, `GET /api/me`
- argon2id, httpOnly-Session-Cookie (`Secure` in prod), Session-Ablauf
- Validierung Benutzername (3–20 Zeichen, eindeutig, case-insensitive) und Passwort (min. 8 Zeichen)
- Rate-Limit für Login/Registrierung pro IP (in prod aus `CF-Connecting-IP`)
- Admin-Flag und CLI-Skript zum Zurücksetzen eines Passworts

**Nicht drin:**
- UI (WP-014)

## Akzeptanzkriterien
- [x] Registrieren → eingeloggt; Login mit falschem Passwort scheitert ohne Hinweis, ob der Name existiert
- [x] Passwörter werden nie im Klartext gespeichert oder geloggt
- [x] Rate-Limit greift nach N Fehlversuchen
- [x] Session ist im WebSocket-Handshake nutzbar
