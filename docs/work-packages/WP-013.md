# WP-013: Persistenz: Runden und Hand-Historie

## Ziel
Jede Hand und jedes Rundenergebnis wird gespeichert; Punkte landen auf dem Account.

## Scope
**Drin:**
- Hände mit allen Aktionen, Board, gezeigten Karten und Pot-Ergebnissen speichern
- Rundenende: Platzierungen und Punkte in `round_players`
- Laufende Runden überleben einen Server-Neustart nicht zwingend – Verhalten definiert und dokumentiert (z. B. Runde wird abgebrochen ohne Punkte)

**Nicht drin:**
- Statistik-Auswertung (WP-019)

## Akzeptanzkriterien
- [x] Nach einer gespielten Runde sind alle Hände und Ergebnisse in der DB
- [x] Gespeicherte Hand lässt sich in der Engine wieder abspielen und ergibt dasselbe Ergebnis
- [x] Verhalten bei Server-Neustart ist getestet und dokumentiert

## Tests
Integrationstests Server + DB.
