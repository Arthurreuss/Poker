# WP-025: Zweite Domain poker.deinemudda.win

## Ziel
Die App ist zusätzlich unter `https://poker.deinemudda.win` erreichbar; die Domain bleibt in der Adresszeile stehen (D-023).

## Scope
**Drin:**
- `PUBLIC_ORIGIN` mit mehreren, kommagetrennten Origins (Validierung beim Start)
- WebSocket-Origin-Check gegen alle erlaubten Origins
- Smoke-Test und Status nutzen die erste Origin
- Anleitung für Cloudflare (Public Hostname im bestehenden Tunnel)

**Nicht drin:**
- Gemeinsamer Login über beide Domains (Cookies bleiben pro Host)

## Akzeptanzkriterien
- [x] Server akzeptiert WebSocket-Upgrades von jeder konfigurierten Origin, fremde weiter `403`
- [x] Ungültige Einträge in `PUBLIC_ORIGIN` (Pfad, Slash, kein Schema) verhindern den Start
- [x] Anleitung in OPERATIONS.md

## Tests
`config.test.ts` (Parsen, Fehler), `ws.test.ts` (zwei Origins, fremde Origin).
