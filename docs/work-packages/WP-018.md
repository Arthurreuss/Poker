# WP-018: Spielablauf im UI: Aktionen, Timer, Showdown

## Ziel
Man kann am Handy komplett spielen: setzen, erhöhen, Timer sehen, Showdown und Rundenende verstehen.

## Scope
**Drin:**
- Aktionsleiste: Fold, Check/Call, Bet/Raise mit Slider und Schnellwahl (½ Pot, Pot, All-in)
- Vorab-Aktionen (Check/Fold, Call any)
- Timer-Ring am Sitz, Zeitbank-Anzeige
- Showdown: gezeigte Karten, Gewinnerhand-Beschreibung, Pot-Verteilung
- Rundenende: Platzierungen und Punkte
- Verbindungsstatus und Reconnect-Hinweis
- Dezente Animationen (Karten, Chips), abschaltbar

**Nicht drin:**
- Sounds

## Akzeptanzkriterien
- [x] Nur Aktionen aus `legalActions` sind bedienbar
- [x] Eine komplette Runde ist mit 3 echten Browsern spielbar
- [x] Komponenten-Tests für Aktionsleiste und Bet-Slider (Grenzen, Mindest-Raise)
