# WP-015: Lobby: Tische erstellen und beitreten

## Ziel
Spieler sehen offene Tische, erstellen eigene (öffentlich/privat) und treten per Liste oder Link bei.

## Scope
**Drin:**
- Liste öffentlicher Tische mit Live-Updates (Spieler, Blinds, Status)
- Formular: Name, Startstack, Blinds, Blind-Erhöhung, Zeitlimit, Zeitbank, öffentlich/privat (Defaults aus D-012/D-013)
- Einladungslink für private Tische, teilbar über die Share-Funktion des Handys

**Nicht drin:**
- Tischansicht selbst (WP-016)

## Akzeptanzkriterien
- [ ] Erstellter Tisch erscheint bei anderen Spielern ohne Reload
- [ ] Privater Tisch ist nur per Link erreichbar
- [ ] Komponenten-Tests für Formular-Validierung
