# WP-040: Animationen nach der Hand (Bowling-Stil)

## Ziel
Nach jeder Hand läuft in der Pause vor der nächsten Hand eine kurze, lustige Animation wie auf dem Bildschirm einer Bowlingbahn – je Hand eine andere.

## Scope
**Drin:**
- Auswahl der Animationen durch Arthur und Freunde über [animationen-vorschau.html](../animationen-vorschau.html) (Kandidaten von LottieFiles, Lottie Simple License)
- Ausgewählte Animationen als Dateien in der App (CSP erlaubt nur die eigene Origin), Abspielen mit einem Lottie-Player ohne `eval`
- Je Hand eine andere Animation, für alle am Tisch dieselbe (Auswahl aus der Handnummer)
- Respektiert „Animationen aus“ und `prefers-reduced-motion`

**Nicht drin:**
- Eigene Animationen zeichnen
- Ton

## Akzeptanzkriterien
- [ ] Favoriten ausgesucht, Lizenz je Datei geprüft
- [ ] Nach einer Hand läuft eine Animation, in der nächsten Hand eine andere (Komponenten-Test)
- [ ] Alle Spieler sehen dieselbe Animation (Test der Auswahl)
- [ ] Ohne Animationen bzw. mit reduzierter Bewegung keine Animation (Komponenten-Test)
- [ ] CSP bleibt unverändert streng

## Tests
Komponenten-Tests, Unit-Test der Auswahl.
