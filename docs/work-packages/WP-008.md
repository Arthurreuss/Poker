# WP-008: Engine: Freezeout-Runde mit Blind-Leveln und Punkten

## Ziel
Eine komplette Runde läuft über viele Hände, bis einer alle Chips hat, inklusive Platzierungen und Punkten (D-012).

## Scope
**Drin:**
- Runden-Konfiguration (ohne Antes, D-016): Startstack, Blinds, Blind-Struktur (fest oder steigend alle X Minuten), Zeitlimit (nur als Konfig)
- Button-Wanderung, Spieler scheiden aus, Dead-Button-Regel
- Platzierung (gleichzeitiges Ausscheiden: größerer Stack vor der Hand = bessere Platzierung)
- Punkteformel (n − k, Sieger +1) zentral an einer Stelle
- Blind-Level-Wechsel wirkt ab der nächsten Hand; Zeit wird als Parameter übergeben (kein Zugriff auf die Uhr in der Engine)

**Nicht drin:**
- Netzwerk und Persistenz

## Akzeptanzkriterien
- [x] Simulation einer kompletten Runde mit 2 und mit 9 Bots endet immer mit genau einem Sieger
- [x] Platzierungen und Punkte stimmen für Tabellenfälle inkl. gleichzeitigem Ausscheiden
- [x] Blind-Erhöhung greift erst ab der nächsten Hand
- [x] Engine bleibt frei von I/O und Uhrzeit (per Lint-Regel/Import-Check abgesichert)

## Tests
Simulationstests mit Zufalls-Bots (seeded), Tabellentests für Platzierung/Punkte.
