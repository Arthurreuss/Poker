# WP-030: Einladungslink teilen mit Vorschau

## Ziel
Ein Tisch lässt sich mit einem Tipp über WhatsApp, Signal und andere Messenger teilen; im Chat erscheint eine schöne Vorschau mit Bild und Text.

## Scope
**Drin:**
- „Teilen“-Button am Tisch und nach dem Erstellen (Web Share API, Fallback: Link kopieren)
- Open-Graph-/Twitter-Meta-Tags (Titel, Beschreibung, Vorschaubild 1200×630) für Startseite und Einladungslinks, für beide Domains
- Vorschau verrät keine Tischdaten privater Tische (nur allgemeiner Text)

**Nicht drin:**
- Push-Benachrichtigungen

## Akzeptanzkriterien
- [x] Teilen öffnet auf dem Handy das System-Teilen-Menü, am Desktop wird kopiert (Test)
- [ ] WhatsApp-Vorschau zeigt Bild und Titel (manuell geprüft, Screenshot im Log)
- [x] CSP bleibt unverändert streng

## Tests
Komponenten-Test für Teilen, Test für Meta-Tags im Build.
