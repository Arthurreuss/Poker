# WP-028: Admin-Rolle und Berechtigungen

## Ziel
Es gibt eine Admin-Rolle mit serverseitig geprüften Rechten; normale Spieler können nichts davon.

## Scope
**Drin:**
- Migration: Rolle am Nutzer (`player`/`admin`), erster Admin per CLI-Befehl (`npm run prod:admin -- <name>`), nicht über die Web-UI
- Server-Guard `requireAdmin` für `/api/admin/*`, Admin-Aktionen ins Audit-Log (wer, was, wann)
- Rechte: Tische schließen, Spieler sperren/entsperren, Sessions eines Spielers beenden, Feedback als erledigt markieren
- Gesperrte Spieler können sich nicht einloggen, offene Verbindungen werden geschlossen

**Nicht drin:**
- Dashboard-Oberfläche (WP-029)

## Akzeptanzkriterien
- [ ] Nicht-Admin bekommt auf jeder `/api/admin/*`-Route 403 (Test)
- [ ] Sperre beendet Sessions und WebSocket des Spielers (Test)
- [ ] Jede Admin-Aktion steht im Audit-Log
- [ ] D-Eintrag zu Rollenmodell und Audit-Log

## Tests
DB-Tests für Rollen, Sperre und Audit-Log; Server-Tests für Guards.
