# WP-028: Admin-Rolle und Berechtigungen

## Ziel
Es gibt eine Admin-Rolle mit serverseitig geprüften Rechten; normale Spieler können nichts davon.

## Scope
**Drin:**
- Admin-Flag (`users.is_admin`), CLI zum Setzen und `/admin/feedback` gibt es schon (WP-024); hier kommt ein allgemeiner Server-Guard dazu, der für alle Admin-Funktionen gilt
- Server-Guard `requireAdmin` für `/api/admin/*`, Admin-Aktionen ins Audit-Log (wer, was, wann)
- Rechte: Tische schließen, Spieler sperren/entsperren, Sessions eines Spielers beenden, Passwort zurücksetzen
- Gesperrte Spieler können sich nicht einloggen, offene Verbindungen werden geschlossen

**Nicht drin:**
- Dashboard-Oberfläche (WP-029)

## Akzeptanzkriterien
- [x] Nicht-Admin bekommt auf jeder `/api/admin/*`-Route 403 (Test)
- [x] Sperre beendet Sessions und WebSocket des Spielers (Test)
- [x] Jede Admin-Aktion steht im Audit-Log
- [x] D-Eintrag zu Rollenmodell und Audit-Log (D-029)

## Tests
DB-Tests für Rollen, Sperre und Audit-Log; Server-Tests für Guards.
