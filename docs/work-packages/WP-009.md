# WP-009: Datenbankschema und Migrationen

## Ziel
Postgres-Schema für Accounts, Tische, Runden und Hand-Historie, versioniert und automatisch angewendet.

## Scope
**Drin:**
- Migrations-Tool (SQL-Dateien, z. B. node-pg-migrate) und Typen für Queries
- Tabellen: users, sessions, tables, rounds, round_players (Platz, Punkte), hands, hand_actions
- Migrationen laufen beim Serverstart; Testdatenbank für Integrationstests

**Nicht drin:**
- Logik, die die Tabellen beschreibt (WP-010, WP-013)

## Akzeptanzkriterien
- [ ] Frische DB → alle Migrationen laufen durch; zweimal ausführen ist idempotent
- [ ] Integrationstests laufen gegen eine eigene Test-DB und räumen auf
- [ ] Schema ist in ARCHITECTURE.md als Übersicht dokumentiert

## Tests
Integrationstests gegen Postgres (Test-DB im dev-Container).
