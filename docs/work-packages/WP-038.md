# WP-038: Übersicht der Pokerhände

## Ziel
Unter dem Reaktions-Knopf gibt es einen Knopf, der eine Übersicht aller Pokerhände (Royal Flush bis Hohe Karte) mit Beispielkarten und Rangfolge einblendet.

## Scope
**Drin:**
- Knopf unter den Reaktionen am Tisch, öffnet/schließt eine Übersicht (Overlay/Dialog), schließt per Tipp daneben/Escape
- Alle 10 Kategorien in Rangfolge mit kurzer Erklärung und Beispielkarten (vorhandene Karten-Komponente)

**Nicht drin:**
- Wahrscheinlichkeiten

## Akzeptanzkriterien
- [x] Knopf öffnet und schließt die Übersicht (Komponenten-Test)
- [x] Reihenfolge und Namen passen zur Engine (`HAND_CATEGORIES`/`HAND_CATEGORY_NAMES`) (Test)
- [x] Hoch- und Querformat nutzbar
