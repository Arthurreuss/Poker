# WP-033: Admin: verdeckte Karten aufdecken

## Ziel
Ein Admin, der am Tisch sitzt, kann die verdeckten Karten der anderen antippen: sie drehen sich um, erneutes Antippen dreht sie zurück.

## Scope
**Drin:**
- Server schickt verdeckte Karten nur an Admins und nur auf Anfrage (eigene Nachricht, z. B. `admin.reveal`), nie im normalen `table.state`
- Tippen auf verdeckte Karten eines Gegners → umdrehen, erneut tippen → zurück
- Jedes Aufdecken steht im Audit-Log (WP-028)
- Mitspieler erfahren nichts davon (D-027)

**Nicht drin:**
- Deck/kommende Karten ansehen

## Akzeptanzkriterien
- [x] Nicht-Admin bekommt keine fremden Karten, auch nicht über das Protokoll (Test)
- [x] Admin dreht Karten per Tipp um und zurück (Komponenten-Test)
- [x] Aufdecken wird im Audit-Log festgehalten
- [x] Mitspieler bekommen keinerlei Hinweis (Test: keine Nachricht an andere Verbindungen)

## Tests
Server-Tests (kein Leck an Nicht-Admins), Komponenten-Tests.
