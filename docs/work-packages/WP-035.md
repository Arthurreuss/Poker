# WP-035: Admin: eigene Karten neu ziehen

## Ziel
Ein Admin, der in einer laufenden Hand sitzt, tippt auf seine eigenen Karten und bekommt zwei neue – beliebig oft.

## Scope
**Drin:**
- Engine: reine Funktion tauscht die Hole Cards eines Spielers gegen zwei zufällige Karten aus dem Restdeck; die alten Karten kommen an deren Stelle ins Deck (kein Duplikat, keine Karte eines Mitspielers oder des Boards)
- Protokoll `admin.redrawCards { tableId }`, nur Admins, nur eigene Karten, nur in der Setzphase und nicht gefoldet
- Jedes Neuziehen steht im Admin-Protokoll (`table.redraw_cards`)
- Mitspieler erfahren nichts (kein `table.state` an andere, D-032)
- Hand-Historie speichert die tatsächlich gespielten Karten (Replay bleibt stimmig)
- Client: Tippen auf die eigenen Karten zieht neu (nur für Admins)

**Nicht drin:**
- Board- oder Deck-Karten gezielt wählen

## Akzeptanzkriterien
- [x] Engine-Test: neue Karten kommen aus dem Restdeck, Deck + Hände + Board bleiben 52 verschiedene Karten, beliebig oft wiederholbar
- [x] Nicht-Admin bzw. fremde/gefoldete Hand wird abgelehnt (Test)
- [x] Neuziehen wird im Audit-Log festgehalten; Mitspieler bekommen keine Nachricht (Test)
- [x] Gespeicherte Hand nach Neuziehen lässt sich per Replay korrekt nachspielen (Test)
- [x] Admin zieht per Tipp neu (Komponenten-Test)
