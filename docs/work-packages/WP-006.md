# WP-006: Engine: Setzrunden

## Ziel
Eine Hand läuft regelkonform von den Blinds bis zum Ende der River-Setzrunde als reine Zustandsmaschine.

## Scope
**Drin:**
- Dealer-Button, Small/Big Blind, Heads-up-Sonderregeln (Button = Small Blind, agiert preflop zuerst)
- Aktionen: Fold, Check, Call, Bet, Raise, All-in mit Validierung
- No-Limit-Mindest-Raise-Regel inkl. unvollständiger All-in-Raises (öffnen die Setzrunde nicht wieder)
- Straßen: Preflop, Flop, Turn, River; Hand endet, wenn alle bis auf einen gefoldet haben
- Funktion `legalActions(state)` für UI und Server

**Nicht drin:**
- Pot-Aufteilung und Showdown (WP-007)
- Timer (WP-012)

## Akzeptanzkriterien
- [x] Ungültige Aktionen werden mit klarer Fehlerursache abgelehnt, Zustand bleibt unverändert
- [x] Mindest-Raise und unvollständige All-in-Raises verhalten sich wie im Regelwerk
- [x] Heads-up-Reihenfolge preflop und postflop korrekt
- [x] Zustand ist serialisierbar (JSON) und enthält keine Funktionen

## Tests
Szenario-Tests (Aktionsfolge → erwarteter Zustand) für typische und Grenzfälle.
